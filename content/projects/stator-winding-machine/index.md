## Building the tools to build the motor

While developing brushless motors at Nile University's Innovation Hub, I built custom winding machines to support electromagnetic actuator prototyping. The machine forms part of the development work behind the [rim-driven underwater thruster](/projects/rdb-thruster/).

## Machine design

The CAD image shows a compact frame with a vertical guide, a working head, and a base fixture. Creating dedicated tooling allowed the winding process to be considered alongside the motor's geometry and assembly requirements.

## Deliverable

The work covered custom machine development for stator prototyping. The image documents the mechanical design; cycle time, winding accuracy, and production throughput are not quantified in the available material.
